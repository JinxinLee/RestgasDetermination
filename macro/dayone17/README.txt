This set of macros is designed to run the "Day One" scenarios following the Collaboration Meeting Sep. 2017
Mind, this is not the "Phase 1" setup, hence you'll see worse resolutions, missing parts etc.

Fast vs. Full Sim:
It was decided to provide FastSim results until late Oct. 2017
FullSim should be used for hyperon physics, due to their long-distance decays, which the FastSimm cannot handle nicely.
