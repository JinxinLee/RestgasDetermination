SOFT TRIGGER DATA MODES
-------------------------

CODE: 9 digis ABC DEFG HI. 

AB code the CMS energy sqrt(s):

ABC  | sqrt(s)
-----------
240  | 2.40    
377  | 3.77   
450  | 4.50    
500  | 5.00    
550  | 5.50    

Decay files only carry numbers DEFGHI (without energy). The digits DEFG are mode numbers, where the first 3 digits DEF 
correspond to the trigger line code (see below), and G is the event type (for signal resonances generated with another particle,
e.g. like D0 with anti-D0 (G=0) and anti-D*0 (G=1)).

The last two digits HI correspond to the recoil mode

00 : (no recoil)
01 : gamma
02 : pi0
03 : eta
04 : pi0 pi0
05 : pi+ pi-
06 : K+ K-
07 : K0 K0b
08 : eta eta
09 : pi+ pi- pi0


All decays start with pbarpSystem0 -> and includes c.c. if existing:
